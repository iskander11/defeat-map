# Карта поражений

Настольное приложение на Windows (Go + [Fyne](https://fyne.io)) для ведения календаря повреждений объектов по населённым пунктам на интерактивной карте Крыма.

## Возможности

### Карта

- Интерактивная карта (тайлы OpenStreetMap по умолчанию; также доступны Google Карты/Спутник и Яндекс Карты — переключение прямо на карте).
- Зумы 6–15 по всему Крыму упакованы в приложение и работают полностью офлайн сразу после установки; более глубокие масштабы (16–19) подгружаются один раз при первом просмотре области и остаются в постоянном локальном кэше — повторно из интернета не запрашиваются.
- Свободное панорамирование в любую область — тайлы для неё просто подгружаются по мере необходимости.
- Полупрозрачная панель зума/источника карты/координат курсора (WGS84, DMS, UTM) в углу — карта под ней остаётся видна.
- ПКМ по карте — быстрое добавление происшествия в этой точке; город подставляется автоматически по ближайшему известному населённому пункту.

### Происшествия

- Дата (с календарём-пикером или вводом вручную в формате ДД.ММ.ГГГГ), населённый пункт, повреждённый объект, дополнительная информация, точка на карте, цвет маркера (палитра из 7 цветов).
- Список происшествий в боковой панели — компактный (переменная высота строки: без описания строка короче), одиночный клик переносит карту к месту, двойной клик открывает карточку с полной информацией.
- Карточка происшествия — окно только для просмотра (без обрезки текста) с кнопкой «Редактировать», которая уже открывает форму редактирования/удаления.
- **Карточки-выноски на карте**: зажать и потянуть от маркера — появляется линия и карточка с информацией о происшествии, которая остаётся закреплённой на месте (позиция сохраняется между запусками приложения). ПКМ по карточке — удалить (не затрагивая само происшествие). Двойной клик — открыть полную информацию. При зуме ниже определённого порога карточки временно скрываются, чтобы не накладываться друг на друга, и появляются вновь при возврате зума.

### Календарь и отчёты

- Календарь с подсветкой дней по числу происшествий, выбором периода (диапазона дат).
- Отчёт по происшествиям за период (или за всё время): разбивка по городам + список; двойной клик по записи открывает карточку с полной информацией.

### Слои (импорт/экспорт KML/KMZ)

- Вкладка «Слои»: импорт `.kml`/`.kmz` файлов как отдельного слоя точек на карте (синие квадратные маркеры, отдельно от происшествий), с чекбоксом видимости и удалением слоя целиком. Импорт идёт в фоне с индикатором прогресса, не блокируя интерфейс.
- Экспорт текущих происшествий в `.kml`/`.kmz` (для просмотра, например, в Google Earth).

### Прочее

- Поиск и фильтрация по городу.
- Современная тёмная тема, собственная иконка приложения, отсутствие консольного окна при запуске (Windows GUI subsystem).

## Сборка (Windows)

Требуется Go 1.22+ и компилятор C (MinGW-w64/GCC — Fyne использует CGO для OpenGL-рендеринга на Windows).

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
```

Готовый `defeatmap.exe` и папка `assets` появятся в `dist/`.

## Установщик

Если на машине установлен [Inno Setup 6](https://jrsoftware.org/isinfo.php), `scripts/build.ps1` автоматически соберёт ещё и установщик `dist-installer\DefeatMapSetup.exe` (ярлыки в меню «Пуск», опционально на рабочем столе, корректное удаление через «Программы и компоненты»). Собрать установщик отдельно, без пересборки exe:

```powershell
& "$env:LOCALAPPDATA\Programs\Inno Setup 6\ISCC.exe" scripts\installer.iss
```

Установка не требует прав администратора (ставится в пользовательский профиль). Данные происшествий при удалении программы не стираются — см. ниже.

## Иконка

`assets/icon/icon.png` — исходник (256×256), `assets/icon/icon.ico` — многоразмерная версия для Windows. `cmd/defeatmap/rsrc.syso` встраивает её в ресурсы exe (автоматически подхватывается `go build` на Windows) и уже закоммичен — при смене иконки пересоздать командой:

```powershell
rsrc -ico assets/icon/icon.ico -o cmd/defeatmap/rsrc.syso
```

(`go install github.com/akavel/rsrc@latest`, затем также скопировать новый `icon.png` в `cmd/defeatmap/icon.png` — он вшит в бинарник через `go:embed` для иконки окна/панели задач во время работы приложения.)

## Данные пользователя

База происшествий (включая импортированные слои) и кэш тайлов карты хранятся в `%APPDATA%\DefeatMap\` и не входят в репозиторий.

## Структура проекта

```
cmd/defeatmap     — точка входа приложения
cmd/tileseed      — разовая утилита загрузки офлайн-обзора тайлов (уже выполнено для Крыма, z6-15)
internal/store    — модели данных и JSON-хранилище (регионы, города, происшествия, слои)
internal/geo      — математика тайлов и справочник населённых пунктов Крыма
internal/maptiles — дисковый кэш тайлов и загрузчик с учётом политики использования OSM
internal/kml      — минимальный парсер/генератор KML и KMZ (импорт/экспорт слоёв)
internal/ui       — виджеты Fyne: карта, календарь, боковая панель, диалоги, слои, тема
assets/tiles      — упакованный офлайн-обзор карты Крыма (z6-15)
assets/icon       — исходники иконки (icon.png, icon.ico)
scripts/build.ps1     — сборка exe (+ установщика, если есть Inno Setup)
scripts/installer.iss — скрипт Inno Setup
```

## Источники карт

- **OpenStreetMap** (по умолчанию) — © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors. Тайлы загружаются по одному, по мере необходимости, с соблюдением [политики использования тайл-сервера OSM](https://operations.osmfoundation.org/policies/tiles/).
- **Google Карты/Спутник** и **Яндекс Карты** — неофициальный доступ к общедоступным тайловым URL (не по ToS/API этих сервисов); может перестать работать без предупреждения, если провайдер сменит схему адресов.
