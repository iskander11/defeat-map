# Карта поражений

Настольное приложение на Windows (Go + [Fyne](https://fyne.io)) для ведения календаря повреждений объектов по населённым пунктам на интерактивной карте Крыма.

## Возможности

- Интерактивная карта Крыма (тайлы OpenStreetMap), с панорамированием, зумом и подписями улиц вплоть до близких масштабов (17+).
- Низкие масштабы (6–12) карты Крыма упакованы в приложение и работают полностью офлайн сразу после установки; более глубокие масштабы (13–19, включая нужный 17) подгружаются один раз при первом просмотре области и затем остаются в постоянном локальном кэше — повторно из интернета не запрашиваются.
- Фиксация происшествий: дата, населённый пункт, повреждённый объект, дополнительная информация, точка на карте.
- Поиск и фильтрация по городу; клик по происшествию в списке или в отчёте переносит карту на его местоположение.
- Календарь с подсветкой дней, выбором периода (диапазона дат) и отчётом по происшествиям за период (разбивка по городам + список).
- Свободное панорамирование карты в любую область — тайлы просто подгружаются по мере необходимости; кнопка «Добавить карту» позволяет вручную завести ещё один регион/проект.
- Кнопки +/- и индикатор текущего масштаба на карте.
- Современная тёмная тема, собственная иконка приложения, отсутствие консольного окна при запуске (Windows GUI subsystem).

## Сборка (Windows)

Требуется Go 1.22+ и компилятор C (MinGW-w64/GCC — Fyne использует CGO для OpenGL-рендеринга на Windows).

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
```

Готовый `defeatmap.exe` и папка `assets` появятся в `dist/`.

## Установщик

Если на машине установлен [Inno Setup 6](https://jrsoftware.org/isinfo.php), `scripts/build.ps1` автоматически соберёт ещё и установщик `dist-installer\DefeatMapSetup.exe` (ярлыки в меню «Пуск», опционально на рабочем столе, корректное удаление через «Программы и компоненты»). Собрать установщик отдельно, без пересборки exe:

```powershell
& "$env:LOCALAPPDATA\Programs\Inno Setup 6\ISCC.exe" scripts\installer.iss
```

Установка не требует прав администратора (ставится в пользовательский профиль). Данные происшествий при удалении программы не стираются — см. ниже.

## Иконка

`assets/icon/icon.png` — исходник (256×256), `assets/icon/icon.ico` — многоразмерная версия для Windows. `cmd/defeatmap/rsrc.syso` встраивает её в ресурсы exe (автоматически подхватывается `go build` на Windows) и уже закоммичен — при смене иконки пересоздать командой:

```powershell
rsrc -ico assets/icon/icon.ico -o cmd/defeatmap/rsrc.syso
```

(`go install github.com/akavel/rsrc@latest`, затем также скопировать новый `icon.png` в `cmd/defeatmap/icon.png` — он вшит в бинарник через `go:embed` для иконки окна/панели задач во время работы приложения.)

## Данные пользователя

База происшествий и кэш тайлов карты хранятся в `%APPDATA%\DefeatMap\` и не входят в репозиторий.

## Структура проекта

```
cmd/defeatmap     — точка входа приложения
cmd/tileseed      — разовая утилита загрузки офлайн-обзора тайлов (уже выполнено для Крыма)
internal/store    — модели данных и JSON-хранилище
internal/geo      — математика тайлов и справочник населённых пунктов Крыма
internal/maptiles — дисковый кэш тайлов и загрузчик с учётом политики использования OSM
internal/ui       — виджеты Fyne: карта, календарь, боковая панель, диалоги, тема
assets/tiles      — упакованный офлайн-обзор карты Крыма
assets/icon       — исходники иконки (icon.png, icon.ico)
scripts/build.ps1     — сборка exe (+ установщика, если есть Inno Setup)
scripts/installer.iss — скрипт Inno Setup
```
